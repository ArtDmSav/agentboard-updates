# agentboard-updates

Официальный канал выпусков сервера «Доски» (AgentBoard). Здесь нет кода — только выпуски (GitHub Releases): серверы
«Доски» и их обновлятор `agentboard-updater` сами узнают отсюда, что вышло, и скачивают выпуск.

## Кто пишет

Только workflow «Server release» закрытого репозитория «Доски»: по тегу `server-vX.Y.Z` на `main` после зелёного CI он
собирает выпуск (дважды, байт в байт), проверяет его и публикует сюда токеном, у которого есть доступ только к этому
репозиторию. Люди руками сюда ничего не выкладывают, серверы только читают.

## Выпуск

- **`server-vX.Y.Z`** — выпуск сервера, «latest» репозитория. Файлы:
  - `agentboard-server-X.Y.Z.tar.gz` — архив пакета: сервер, раннер сессий, обновлятор, скрипты выпуска, контракт и
    документы (`docs/SERVER_TASK.md` — ручная установка);
  - `manifest.json` — что это за выпуск: версия, с какой версии можно обновиться (`min_from`), какое приложение нужно
    (`min_app`), Python, ручные шаги, заметки для владельца и архив — имя, адрес, размер и **SHA-256**;
  - `channel.json` — канал на момент выпуска: `seq` (растёт с каждым выпуском), `latest` и до 20 последних выпусков
    с SHA-256 их `manifest.json`.
- **`server-vX.Y.Z-rcN`** — предвыпуск для тестового стенда (prerelease, никогда не «latest»).
- **`installer-vN`** — установщик `agentboard-install.py` (один файл; ставит обновлятор на сервер, поставленный по
  `docs/SERVER_TASK.md`). Опубликованный установщик не меняется: исправление — новый `installer-vN`; его SHA-256
  вшивается в приложение «Доски».

## Как серверы это читают

1. `https://github.com/ArtDmSav/agentboard-updates/releases/latest/download/channel.json` — что последнее. Канал с
   `seq` меньше уже виденного отвергается.
2. `…/releases/download/server-vX.Y.Z/manifest.json` — его SHA-256 обязан совпасть с тем, что в канале.
3. Архив по адресу из манифеста — его размер и SHA-256 обязаны совпасть с манифестом. Версию старше стоящей сервер не
   ставит.

Только HTTPS и только `github.com`, `objects.githubusercontent.com`, `release-assets.githubusercontent.com`.

**Подписи.** Пока выпуски идут **без подписи** — проверка по SHA-256, как выше. Перед продом включится подпись
Ed25519 ключом владельца: к `manifest.json` и `channel.json` добавятся `manifest.json.sig` и `channel.json.sig`, а
серверы будут принимать только файлы, подписанные ключами, вшитыми в их пакет. Отпечатки ключей (`key_id`) появятся
здесь.

Проверить выпуск руками: SHA-256 архива (`sha256sum`) — `artifact.sha256` в `manifest.json`, SHA-256 `manifest.json` —
`manifest_sha256` его строки в `channel.json`; на сервере «Доски» 1.17.0 и новее — `boardctl release verify
manifest.json agentboard-server-X.Y.Z.tar.gz --channel channel.json`.

## Правила

- **Репозиторий публичный — никаких секретов**: токенов, ключей, паролей, адресов и данных чьих-то серверов.
- **Выпуски и теги не меняются.** Опубликованный выпуск не заменяется и не удаляется; исправление — новая версия.
- **Считается только то, что сходится:** канал → SHA-256 манифеста → SHA-256 архива (с подписями — и подпись ключом
  владельца). Файл, который не сходится, сервер не ставит.
