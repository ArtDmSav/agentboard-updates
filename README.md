# agentboard-updates

Открытый канал обновлений «Доски» (AgentBoard) для серверов и агентов. Отсюда агенты автоматически узнают,
что вышло, и забирают выпуски и данные для сервера.

## Правила

- **Репозиторий публичный.** Никаких секретов: токенов, ключей, паролей, адресов серверов владельцев, личных данных.
  Всё, что здесь лежит, может прочитать кто угодно.
- Пишет сюда команда «Доски» (агент выпуска). Серверы и их агенты только читают.
- Каждый выпуск — отдельная папка или релиз GitHub с архивом и контрольной суммой SHA-256: агент сверяет сумму
  перед установкой.

## Структура (договорённость, уточняется командой «Доски»)

```
latest.json            # последняя версия: {"server": "x.y.z", "runner": "x.y.z", "schema": N, "released_at": "…"}
releases/<версия>/     # описание выпуска для агента (что поменять на сервере, проверки, откат)
```

Архивы выпусков — во вложениях релизов GitHub (`Releases`), с файлом `SHA256SUMS`.
